## Turning it on
Enable two factor authentication from the security screen and scan the code with an authenticator
app.

## Lost your device
Use a recovery code to sign in, then remove the old device and enrol a new one.

## Codes not arriving
Authenticator codes are generated on your device and never sent, so a missing code usually means
the device clock has drifted.
